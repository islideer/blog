- 自定义变量的 !important，以下结果为 蓝色。自定义属性可以包含 !important，但这会被 CSS 解析器从“属性值”中删除，但是在自定义的规则中“important”生效

```css
.example5 {
  --color: red !important;
  --color: blue;

  color: var(--color);
  /* 没有下面一行将是红色，有下面这一行是蓝色 */
  color: blue;
}
```

- hwb() 也是新增的颜色方法之一，其他类似的：

  - HWB 代表色相-白度-黑度
  - HSL（色相、饱和度、亮度）
  - LAB （亮度、a 轴和 b 轴）
  - RGB（红、绿、蓝）
  - CMYK（青、品红、黄、黑）
  - HSB/HSV（色相、饱和度、明度/值），类似于 HSL，但使用明度或值来代替亮度

- 尽量使用 :is()，在需要降低权重时，使用 :where()

- :has() 可以和伪类正常工作，但是无法和伪元素正常工作
- Cascade layers：@layer xxx，后出现的层级优先级高，且层级内的规则是单独的，即便是后面层的 css 权重低
- 在移动设备上有小视口和大视口之分：svh、lvh、dvh 动态决定
- lab() 、 hwb() 、 lch() 或 oklch() 等新颜色函数仅支持空格分隔的语法

- background: var(--background-image); 而不是 background: url(var(--background-image));
- aspect-ratio 控制元素的宽高比，适合快速创建正方形等

- float: inline-start; clear: inline-start; 逻辑属性清除浮动

- @supports() 检测是否支持指定的 css 属性或者选择器 selector，也可以使用 not 反向查询

```css
@supports (display: grid) {
  .grid {
    display: block;
  }
}

@supports not selector(:has(a)) {
  .has {
    display: block;
  }
}
```

```css
  }
}
```
