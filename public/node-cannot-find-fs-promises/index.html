    • Cannot find module 'fs/promises'

    原因

    很有可能是 node 版本太低导致的。

    node 13 及以下版本的 fs promises 引用方式：

    node 14 及以上版本的 fs promises 引用方式：

    解决方案

    1. 升级 node 版本至 14 及以上。

    注意：Win7 及以下版本不支持 node 14 及以上版本，所以此方法在 Win7 及以下系统版本不适用。

    2. 修改引用方式

    将所有 fs promises 的引用方式修改为 13 版本的方式。

    The End.
